# PetGame Server

A clean Maven starting point for learning Spring Boot and Spring Data JPA.

Requirements: JDK 26 and Maven.

## Structure

- `src/main/java`: application code
- `src/main/resources`: application configuration and database migrations
- `src/test/java`: tests

The project currently has no application code or dependencies and cannot run a server yet.
We will add Spring Boot, entities, repositories, services and controllers step by step.
The PetGame client is a separate project.

The previous server files and local configuration are backed up in `.backups/`.
These archives may contain database credentials and are ignored by Git.
